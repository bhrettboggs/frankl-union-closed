## 4. Hub families [PROVED]

For t ≥ 1 and k = 2t+1, let P_i = {2i, 2i+1} for i < t, with hub h = 2t. Define

H_t = {∅} ∪ {U_I, U_I ∪ {h} : ∅ ≠ I ⊆ [t]} ∪ {Z ∖ {2i+1} : i < t},  where U_I = ⋃_{i∈I} P_i.

**Proposition H.** H_t is valid, with |H_t| = 2^{t+1} + t − 1 and μ(H_t) = t + 1 = ⌈k/2⌉.

*Proof.* Unions of sets of the form U_I or U_I ∪ {h} are again of that form. Any union with a co-singleton is either that co-singleton or Z = U_[t] ∪ {h}. There are no singletons. Separation: 2i is separated from 2i+1 by Z∖{2i+1}, elements of different pairs by U_{i}, and the hub from pair elements by U_{i} versus U_{i}∪{h}. Counts: a kept element 2i lies in 2·2^{t−1} union-type members and in all t co-singletons, so c = 2^t + t and 2c − n = t + 1. The hub and the non-kept elements have c = 2^t + t − 1, so 2c − n = t − 1. ∎

Checked by `hub_family.py` for t = 1..5. H₃ is class 5 above, so it is a minμ(7) attainer. H_t matches B(2,…,2,3) in μ, so it does **not** improve the upper bound. It is a structurally different extremal family with about twice as many members. Deleting the hub gives M_{2t}.
